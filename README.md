# نقوش — Website V2

نسخة معاد تصميمها بالكامل لبراند «نقوش».

## أهم التغييرات
- معالجة الصور الأصلية قبل استخدامها:
  - denoise خفيف
  - local contrast محسوب
  - Lanczos upscale من 206×206 إلى 824×824
  - sharpening بسيط يحافظ على الرسم
  - WebP عالي الجودة
- إعادة تصميم الموقع من الصفر بحيث لا يتم تكبير الصور الصغيرة بشكل مبالغ.
- Founder section:
  - Aliaa Gamal — Co-Founder
  - Omina Gamal — Co-Founder
- Arabic-first RTL.
- معرض كامل لـ 24 عملاً.
- Lightbox بحجم مقيد للحفاظ على جودة الصور.
- CTA إلى صفحة Facebook.
- قسم للطلبات الخاصة.
- Responsive.

## تشغيل المشروع
```bash
npm install
npm start
```

ثم:
`http://localhost:4200`

## مهم
الصور التي تم رفعها أصلًا كانت 206×206 بكسل فقط. النسخة الحالية تحسن مظهرها وتمنع عرضها بأحجام تفضح دقتها، لكن أفضل نتيجة نهائية ستظل من الصور الأصلية عالية الدقة إذا توفرت لاحقًا.
