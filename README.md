# Nuqoush — نقوش

An Arabic-first visual brand website built with Angular for **Nuqoush**, an art brand founded by **Aliaa Gamal** and **Omina Gamal**.

The website is designed to present original artwork through a calm, gallery-led experience with strong emphasis on visual identity, RTL layout, responsive presentation, and commission-focused calls to action.

🌐 **Live Demo:**  
https://noqosh.vercel.app/

---

## Overview

Nuqoush is a visual art brand centered around original artwork inspired by Arabic calligraphy, geometric ornament, botanical details, and decorative compositions.

The website was created to give the brand a dedicated digital presence beyond social media and to present the artwork in a more curated, professional way.

The experience is primarily Arabic-first and designed around the artwork itself.

## Features

### Artwork-Focused Experience

The interface is intentionally designed around the art rather than around traditional corporate UI.

Key features include:

- Artwork-led hero section
- Curated featured pieces
- Full artwork gallery
- Category filtering
- Artwork lightbox previews
- Responsive image presentation
- Brand storytelling sections
- Commission-focused calls to action

---

### Arabic-First RTL Design

The project was designed for Arabic content from the start.

It includes:

- Full RTL layout
- Arabic-first typography
- Responsive Arabic text
- RTL-safe spacing
- Mobile-friendly navigation
- Direction-aware alignment

---

### Artwork Gallery

The gallery presents the brand's artwork in a clean visual layout.

Users can:

- Browse the full collection
- Filter artwork by category
- Open artwork in a larger lightbox view
- Explore featured pieces
- Navigate comfortably on desktop and mobile

---

### Commission Experience

The website includes content and calls to action for custom artwork requests.

This supports the brand's real sales activity without pretending to provide full e-commerce functionality.

The website does **not** include:

- Checkout
- Payment processing
- Shopping cart
- Backend order management

Instead, visitors are directed to contact the brand for availability and custom requests.

## Visual Direction

The visual identity was inspired by the artwork itself.

The interface uses a restrained palette built around tones such as:

- Ivory
- Teal
- Sage
- Gold
- Muted Rose
- Warm neutral tones

The goal is to keep the interface quiet enough for the artwork to remain the main focus.

---

## Image Handling

The artwork images used in the site were prepared for web presentation before being placed into the gallery.

The site avoids unnecessary stretching and uses controlled framing and image sizing to preserve the visual quality of the source artwork.

---

## Responsive Design

The website is designed to work across:

- Desktop
- Tablet
- Mobile

Special attention was given to:

- Artwork sizing
- Gallery spacing
- RTL typography
- Mobile navigation
- Lightbox behavior
- CTA readability

## Getting Started

Clone the repository:

```bash
git clone https://github.com/omargamal-og/noqosh.git
```

Enter the project directory:

```bash
cd noqosh
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Then open:

```text
http://localhost:4200
```

---

## Production Build

Create a production build with:

```bash
npm run build
```
